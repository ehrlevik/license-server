# System Zarządzania Licencjami

## Opis
System do generowania i weryfikacji licencji oprogramowania.

## Jak używać
1. **Panel HTML** - otwórz `index.html` w przeglądarce
2. **Generuj licencje** - używaj zakładki Generator
3. **Zarządzaj licencjami** - dezaktywuj, aktywuj w zakładce Panel
4. **Weryfikacja** - użyj programu `license_checker.py`

## Weryfikacja w CMD
```bash
python license_checker.py ABCD-EFGH-IJKL-MNOP
